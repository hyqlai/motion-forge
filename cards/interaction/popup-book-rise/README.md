# 纸艺立体书升起 (component/popup-book-rise)

纯正纸艺与折纸美学：场景在透视俯视下打平，多张网格卡片沿底边错峰立起（90度弹簧翻折带物理过冲回弹），根部阴影随站立角度收窄变实。

## 意图

手绘风故事短片、童话与绘本感叙事、轻松产品陈列、生活方式展示。

## 动效核心

- 3D 透视打平俯视场景；
- 卡片沿底边错峰立起，带弹簧回弹；
- 根部阴影随折纸角度收紧变窄。

## 参数表

- `theme`: 调色主题；
- `durationInFrames`: 总时长，默认 134 帧。

## 已知坑

- 极度严肃冷酷的商务数据报告不建议使用；
- 卡片文字不宜过长过多。

## 复用指引

用于手绘插画、绘本故事、文创生活方式与创意功能陈列。
