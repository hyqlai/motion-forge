# 命令面板呼出 (component/command-palette-summon)

Raycast 与 Spotlight 级极客交互：背景压暗失焦，⌘K 命令浮窗从上方轻快弹落，快捷行错峰浮现，模拟打字实时收窄候选列表并高亮命中首条。

## 意图

开发者工具发布、SaaS 效率软件宣传、快捷键与自动化能力演示。

## 动效核心

- 全局背景径向压暗并带深度模糊；
- ⌘K 面板从中心上方微过冲弹落；
- 候选行错峰淡入，模拟按键实时过滤收窄列表并高亮首行。

## 参数表

- `theme`: 调色主题；
- `durationInFrames`: 总时长，默认 120 帧。

## 已知坑

- 不适于纯故事生活类场景；
- 输入字符数应短促精准（2~6 字母）。

## 复用指引

用于生产力工具、桌面端客户端宣传、极客工作流展示。
