# 冲刺礼炮纸屑 (component/counter-confetti)

大数字由慢到快急速冲刺至目标里程碑，数字撞停前夕从两侧爆发喷射52片带物理重力、空气阻力与自转飘落的多彩纸屑，形成强烈的胜利与庆祝高潮。

## 意图

里程碑数字公布（如突破 1000 万用户、达成 100% 目标）、视频核心高潮点与成就解锁。

## 动效核心

- 数字带缓动加速冲刺，终点过冲回弹；
- 撞停前夕向两侧 burst 喷发 52 粒多色物理纸屑；
- 纸屑受重力与阻力作用翻转飘落。

## 参数表

- `target`: 冲刺目标数值，默认 1000；
- `label`: 顶部里程碑标签，默认 "MILESTONE REACHED"；
- `theme`: 调色主题；
- `durationInFrames`: 总时长，默认 138 帧。

## 已知坑

- 不适于严肃沉闷的论证语境；
- 纸屑爆发要抢在数字落定前 4~6 帧，避免滞后。

## 复用指引

用于商业里程碑发布、用户数暴涨、比赛胜利等高情绪释放段落。
