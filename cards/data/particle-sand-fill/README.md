# 粒子落砂成柱 (component/particle-sand-fill)

重力加速度驱动实体方点粒子错峰倾泻而下，触地面与各层顶面碰撞弹跳堆积，层层筑高成柱状图后交接实体柱并弹出数值标签。

## 意图

硬核数据对比、年度吞吐量、并发数指标呈现。需要摆脱死板拉伸、呈现物理沙漏堆积质感的图表。

## 动效核心

- 方块粒子按重力公式落向各层堆积面；
- 落地时触发回弹与微小挤压；
- 堆积完毕后平滑淡入实体柱，弹出数值气泡标签。

## 参数表

- `theme`: 调色主题；
- `durationInFrames`: 总时长，默认 150 帧。

## 已知坑

- 数据列数过多会导致粒子过于密集；
- 堆积需要留出物理落下的视觉时间，语速过快时不建议过度压缩时长。

## 复用指引

适合科技宣传片、硬核科普与技术指标发布。
