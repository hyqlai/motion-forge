# 胶带拍贴固定 (component/masking-tape-slap)

手工纸张质感：卡片轻飘入位后悬浮微晃，两条半透明纸胶带先后从画外加速拍在对角（大尺度过冲压扁），第二条拍下瞬间卡片晃动归零、投影收紧下沉。

## 意图

手帐日常、观点立论、生活方式短片、手工纸艺。

## 动效核心

- 卡片轻微浮动悬晃；
- 半透明和纸胶带先后从斜向拍下；
- 第二条胶带拍下瞬间整卡晃动归零并轻微下沉压实。

## 参数表

- `title`: 卡面主标题；
- `subtitle`: 眉标说明；
- `theme`: 调色主题；
- `durationInFrames`: 总时长，默认 140 帧。

## 已知坑

- 不适于过于刻板冷酷的商务图表；
- 胶带拍下的帧数节奏要利落清脆。

## 复用指引

用于手写体标题、手帐日常记录、人情味叙事短片。
