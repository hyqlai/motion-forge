# 机械翻牌屏 (text/split-flap-flip)

复刻复古机场与老火车站的机械翻牌时刻表（Split-Flap），上下折半牌片带3D翻转透视与暗部阴影，左到右级联翻过中间乱码后整齐咬合在目标标题上。

## 意图

故事短片开场、重大航程/项目启动、产品发布会日期与核心口号。

## 动效核心

- 字符拆为上下两半独立的 3D 翻转片；
- 从左向右以级联波浪翻过中间字符；
- 翻到目标文字瞬间对齐咬合，中间分界线清晰稳定。

## 参数表

- `text`: 目标标题文字（建议英文字符）；
- `theme`: 调色主题；
- `durationInFrames`: 总时长，默认 140 帧。

## 已知坑

- 文字超过 14 个英文字符会导致单字过小；
- 全片不宜多次重复使用，单次开场惊艳感最强。

## 复用指引

用于科技短片、旅行主题、历史回顾或发布片第一镜时空交代。
